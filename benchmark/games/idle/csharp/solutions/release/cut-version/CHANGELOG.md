# Changelog

## [1.1.0] - 2026-10-25

- Version 1.1.0, shown on the settings screen.

## [1.0.0] - 2026-10-24

- An idle hive at dusk: Gather, five producers whose prices grow with each one bought, buy 1, 10 or as many as you can.
- Upgrades for each producer, for Gather and for everything.
- The dawn: trade a night's glow for embers, each adding 10% to all production.
- Time away pays up to 8 hours; a clock set back pays nothing.
- Settings (volume, English, German, French) and credits; saves from version 0.x keep their embers.
- Portrait layout for phones, tablets and desktops; Linux and Android builds.
