# Reading players' fun, and further reading (game-design reference)

## Lazzaro's four keys

Nicole Lazzaro's four keys to fun come from watching players rather than from the rules: XEODesign's cross-genre research on
gamers, first presented at GDC 2004 as *Why We Play Games: Four Keys to More Emotion*
([summary](https://www.nicolelazzaro.com/the4-keys-to-fun/)). In her words:

| Key | What the player feels |
|---|---|
| Hard fun | fiero: in-the-moment personal triumph over adversity |
| Easy fun | curiosity |
| Serious fun | relaxation and excitement |
| People fun | amusement |

They name the emotion a playtester shows, where MDA's eight kinds name what the game is for. Use them to read a playtest
against the GDD's main kinds of fun:

| The player shows | The GDD's kind that is working |
|---|---|
| fiero after a hard try (a fist, a shout, "again") | challenge |
| curiosity (stops to look, tries things, asks what is behind a door) | discovery, fantasy or sensation |
| relaxation or excitement that changes how they feel away from the game | submission, or what the game is about for them |
| amusement between players (laughing, teasing, helping) | fellowship |

The match is ours, not hers, and it is loose. When the emotion a GDD's main kind promises never shows up in a playtest, that
kind is not working yet; write what was seen in the GDD (`game-playtest`). The `Fun:` line still uses the eight kinds.

## Further reading

When the user wants to read further:

- Raph Koster, *A Theory of Fun for Game Design*: fun is learning, so a game the player has mastered stops being fun.
- Jesse Schell, *The Art of Game Design: A Book of Lenses*: lenses, sets of questions to ask in a review.
- Katie Salen and Eric Zimmerman, *Rules of Play: Game Design Fundamentals*: game systems, the academic treatment; their
  *The Game Design Reader* has Marc LeBlanc's essay "Tools for Creating Dramatic Game Dynamics".
- Steve Swink, *Game Feel*: input, response and context, moment to moment (`game-juice`).
- Michael Sellers, *Advanced Game Design: A Systems Approach*: interconnected systems, for strategy, simulation and RPGs.
- Marc LeBlanc's own list of the eight kinds, with talks and papers: [8kindsoffun.com](http://www.8kindsoffun.com/) (plain
  HTTP; its labels differ slightly from the paper's, for example "game as soap box" for expression).
