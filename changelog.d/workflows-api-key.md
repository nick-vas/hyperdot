Added: the Evals and Token benchmark workflows take an `auth` input: `subscription` (the default, the `CLAUDE_CODE_OAUTH_TOKEN` secret) or `api-key` (the `ANTHROPIC_API_KEY` secret, billed to the API account). Only the chosen secret reaches each job, and `.github/scripts/Initialize-ClaudeAuth.ps1` checks it with one small request before anything runs, naming the secret that is missing or refused.
