Added: `soak -PlayersPerClient <n>` for games too big for one Godot process per player: each client is started with `--soak-players=<n>`, the server with `--soak-players=<clients x n>` beside `--soak-clients`, and `soak.players` counts them (#304). When `soak-leak` fires for a process that printed no heap metric of its own, its message suggests `[soak] metric managed_heap_after_gc_mb`, since process memory also grows when a runtime only holds what it freed (#310).
