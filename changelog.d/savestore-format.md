Changed: the C# example's `SaveStore` takes the save format name and `bareVersionOne` as parameters instead of a fixed `"breakout-save"`, so a game can copy it unchanged. `bareVersionOne` (off by default) reads a file without the envelope as version 1 only for a game whose first release wrote one; with it off, any other JSON at the save path loads as `Corrupt` and is left alone. The example passes `"breakout-save"` and `bareVersionOne: true`, and its golden files load as before (#308).
