Added: `Update-AddonStatus.ps1` (the weekly canary) reads the newest release's zip of each add-on in `addons-status.json` (listed, never extracted or run) and compares its `addons/<name>/` folder and `.gdextension` file with the entry: a folder under another prefix is applied, a missing folder or file, a gone asset or a repository with a first release is reported for a person, and an API or download that cannot be reached is a note. Each entry with a release zip records it as `releaseZip` (tag, asset, prefix, date checked); the folders of Godot Jolt, godot-steam-audio and py4godot were confirmed against their zips on 2026-10-29.
