Changed: a flag given to a command that does not read it is refused as `invalid-arguments`, naming the commands that take it (`soak -BudgetMs`: "-BudgetMs is for bench, deck, not soak"), instead of being ignored, so a check that never ran cannot pass for one that did. The GitHub action passes each of its inputs only to the commands that read it. A script that hands the same flags to several commands (`-Output` to `test`, `-Runners` to `export`) now fails and must pass each command its own.
