Changed: a flag given to a command that does not read it is refused as `invalid-arguments`, naming the commands that take it (`soak -BudgetMs`: "-BudgetMs is for bench, deck, not soak"), instead of being ignored, so a check that never ran cannot pass for one that did. The GitHub action passes each of its inputs only to the commands that read it. `-Results` and `-Output`, which only say where files go, are taken by every command, so a script can still hand the same folders to each command it runs; a script that hands other flags to several commands (`-Runners` to `export`, `-Coverage` to `build`) now fails and must pass each command its own.
