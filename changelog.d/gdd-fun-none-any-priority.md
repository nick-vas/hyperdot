Changed: `Fun: none` is valid at any GDD priority: a `must` or `should` feature can be work the game needs that serves no kind of fun (credits a licence requires, crash reports, cloud saves) without claiming a kind it does not serve or dropping to `could`. `doctor` no longer fails it; `status -Json` lists such features as `gdd.supportFeatures` for a design review, and the `game` and `game-design` skills no longer treat them as the first to cut (#285).
